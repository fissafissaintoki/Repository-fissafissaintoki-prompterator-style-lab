# KYRON Market Radar Mobile v0.2

Öffentliche mobile PWA für Live-Krypto-Marktbeobachtung.

## Funktionen

- Binance Spot WebSocket
- sekündliche Kursaktualisierung
- Rolling-High-Breakout-Erkennung
- Momentum- und Volumenfilter
- Breakout- und Watch-Signale
- installierbare Mobile-Web-App
- keine API-Keys
- keine automatische Orderausführung

## GitHub Pages

Repository Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.

Danach ist die App unter der GitHub-Pages-Adresse des Repositorys erreichbar.

## Governance

Nur Marktbeobachtung. Kein Profitversprechen und keine autonome Handelsausführung.
